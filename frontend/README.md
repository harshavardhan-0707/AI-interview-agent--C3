# Frontend - AI Interview Agent

Modern React + Vite + Tailwind CSS frontend interface for conducting AI-powered technical interviews.

## Features
- Candidate profile launcher & selection modal
- Live interactive chat interface with typing indicators
- Interview progress bar & stage visualization
- End-of-interview feedback dashboard displaying summary, strengths, skill gaps, and next steps

## Setup & Running
```bash
npm install
npm run dev
```

The application connects to `http://localhost:8000/api/interview` by default.
